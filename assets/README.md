# Local scene assets

Place lawfully obtained, non-redistributable AODT scene archives under:

```text
assets/scenes/<scene_id>/<scene_id>.zip
```

Only this README is tracked. Everything else under `assets/` is ignored by
Git. Open the complete [English placement and format guide](../docs/CONFIG_AND_SCENES.md)
or [繁體中文規範](../docs/CONFIG_AND_SCENES.zh-TW.md) for archive structure,
Worker-side placement, and configuration formats.
