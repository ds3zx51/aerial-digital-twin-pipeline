# AODT_COLORAN_MATCHED planning profile

The audit tables in this directory are planning artifacts only. They define
candidate Rome/ColO-RAN-compatible inputs and semantic questions without
creating a scene or running AODT. No executable COLORAN profile or generated
scene is distributed by this repository.

Null/TBD fields are deliberate gates. A profile is not executable until
geography, scene rights, RAN telemetry availability, estimator semantics, and
configuration review are complete. The profile never authorizes changing
propagation or AdvTabDDPM parameters to improve agreement after observing
results.
