# AERPAW Lake Wheeler scene inputs

The checked-in `source/osm/lake_wheeler_osm_smoke_v1.osm` file is a pinned
OpenStreetMap snapshot for deterministic smoke and plumbing tests. Its bounding
box, SHA-256 digest, element counts, acquisition URL, attribution, and AODT
handoff are recorded in the adjacent `source_manifest.json` file.

OpenStreetMap data is © OpenStreetMap contributors and licensed under ODbL 1.0.
Preserve that attribution when copying or adapting the snapshot.

The OSM snapshot is not the paper's supplementary foliage reconstruction and
cannot satisfy the formal BU07 scene gate. See `REQUIRED_EXTERNAL_INPUTS.md` for
the artifacts required by a formal run.
